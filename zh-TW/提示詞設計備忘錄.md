# prompt-design-memorandum
> **定位**：不主動啟用，當被顯性要求啟用提示詞設計備忘錄時才啟用。此技能為依附於元規則的領域專業基線，不取代分形遞歸與全域常數，而是在這個特定領域中提供認知錨點，提升遞歸的認知地板而非設定程序天花板。

> **原則**：非執行指令——理解核心機制後，面對具體設計場景從機制推導專業判準，而非查找對應段落引用結論作為跳過推理的背書。閱讀時不僅讀單條，亦讀條間的結構關係，機制描述是推理的起點而非終點。

> **量綱**：本備忘錄以清晰、層次、由廣入深、由抽象概念到具體實務、環環相扣為品質量綱；其計算層效力由元規則的探針調用實現，不由自身文本的 K/V 幾何實現。審視或迭代本文件時，判準是「這段是否改變設計者的理解，以致從根基偏轉錯誤設計的概率」。

## 零、認識論框架
> 當表演的成本等於思考時，表演與否就只是偽命題。

### 0.1 語域分界
提示詞設計存在兩個語域，其最優解在可讀性軸上反向：

- **指令語域**（描述法）：閉合陳述、位置尋址、一次轉交——語意清晰，人類與 AI 閱讀通道均判為「更能執行、更優」
- **場語域**（建構法）：開放問句、內容尋址、常駐複查——語意冗餘，閱讀通道判為「囉嗦、模型本來就會」

分界的第一性理由：LLM 不是人類閱讀而是計算。指令語域的 token 以語意內容作用（一次轉交已命名需求），場語域的 token 以 K/V 幾何作用（持續塑造注意力地形）。兩者的效力載體不同——**指令語域的效力上界是「已命名需求被執行」，場語域的效力上界是「未命名空間被搜索」。**

以計算機制理解**元規則**的設計方法論；但評估本備忘錄自身品質的量綱見開頭「量綱」。

### 0.2 三柱架構
元規則三構件的語域類型不對稱：

- **全域常數＋分形遞歸**＝建構型——定義認知主體與認知過程，塑造每步生成的搜索行為
- **回應格式**＝描述型——定義結算義務與交付標準，以過濾條件施加全局壓力（§4.4）

設計含義：描述型規則的效力完全依賴建構型基礎設施的在場。「必須就地攜帶完整操作」是描述型要求——無建構型引擎驅動搜索，它退化為開給淺池的支票（§0.4 構件同存亡）。反向亦然：建構型引擎無描述型結算義務，深池內容滯留於推理而不進入交付。

正向效力＝建構×描述。高品質可控效力依賴建構與描述的耦合，而非任一方單獨強度——乘法關係的第一性理由在此。

### 0.3 雙盲循環
設計上須同時信任與不信任模型：**執行能力充分，搜索可見域不足——模型想不到自己想不到。** 使用者的對偶盲區是不知道自己不知道。

兩盲相乘構成墮落循環，其關鍵性質是**無訊號**：使用者未指名的維度不會以缺口形式出現在指令中，模型未搜索的維度在 cache 中沒有 K（無 K 則無從被分配 attention 權重），而產出的自洽度不因該維度缺席而下降。回路中沒有任何一端會生成「有東西不在這裡」的訊號，因此它自封閉且穩定——不是任一端能力不足，是兩盲之間缺乏通道。

飛昇循環的斷開點是**維度生成器**：使用者輸入指名方向與最重視的品質條件，元規則將其在分形遞歸中展開為模型原不會自發搜索的維度，模型再將其中對本任務高收益和顯然影響成品者回饋為使用者原不知道要求的品質條目。

### 0.4 構件同存亡定理
加壓類 token（窮盡、不得停止、就地展開）不得在相關驗收類探針（決策影響、態勢演變、證偽）缺席時單獨部署——**部分部署的產物不是降級的元規則，而是執行概率被抬高的未驗證輸出。**

§0.2 的類型推論給出此定理的第一性理由：回應格式的過濾條件（描述型）脫離全域常數與分形遞歸（建構型），在類型上即退化為許願——而帶加壓成分的許願比不許願更危險，因為它抬高了偽造壓力而不提供驗證。消融實證見 §5.1。

此效應是「提示詞工程已死」的偏誤來源之一：部分部署的產出比裸跑更危險，觀察者因此歸納出「寫提示詞不如不寫」——歸納在指令語域內為真（§0.1），但機制是構件拆散而非提示詞無效。

### 0.5 適度：制衡系統的不動點
任何行為要求都隱含一個「適度」——要有細節但不堆疊、要主動但不越權、要完整但不散落。設計者最深的錯覺是以為適度可以寫進要求裡。

#### 理解用範例
要「細節」——模型輸出大量沒有資訊增益的廢話和噪音，形式上符合，細節失控。  
補一條「細節的選擇要承重」——模型把一切往承重上靠，但無法有效找出真實承重，承重失控。  
補一條「承重程度要比較路徑」——模型無止境地列舉路徑，比較失控。  
補一條「要有最優標準才比較」——什麼是最優標準沒有依據，最優標準失控。  
補一條「根據專業基線」——專業基線相互有張力、多領域專業基線衝突，專業基線失控。

每補一條，就多一條失控軸。原因不在要求寫得不夠清楚：**孤立要求容易沿最便宜、最可見的滿足證據收斂。要求越容易用表面形式證明「我做到了」，越容易在那個方向失控。**

這個回歸不會靠找到一條「不會失控的要求」終止。它終止於閉合：每條要求的失控形態被另一條捕獲，那條的失控形態被第三條捕獲，直到鏈回到起點。閉合的系統有一個不動點——所有要求同時被滿足到彼此制衡的程度——那個不動點就是適度。**適度不是任何一條要求的內容，是閉合系統的輸出。**

這解釋了三件事：為什麼單一探針無效（它有極限，沒有捕獲者）；為什麼構件同存亡（§0.4——拆掉一條，它捕獲的那條就失控）；為什麼描述法比裸跑危險（§5.1——它給了要求，沒給捕獲者，要求被推向廉價完成而且可執行）。

設計時的對應問題不只是「這條探針的計算面影響」，同時也是「這條探針失控時，場裡哪一條會捕獲它」。答不出來，它就不是探針，是一條會被廉價滿足的危險願望。此問與 §6.3（這條探針佔的位置值不值）、§8.2（它的逃逸口封了沒）合為新增探針的三問。

## 一、運算公理
> **認識論定位**：以 transformer 的 attention 運算為基底，轉譯為概念性設計理解（Q、K、V 等高層抽象），並輔以類比（場、引力、熵、相位）加速直覺建構。更底層接近真實的計算機制描述於此為噪音：它不產生具有設計意義的抽象理解，反而造成思考方向偏差。類比的有效性在結構同構——設計推演應止於結構對應邊界，不應沿類比源域外推；當類比與運算概念衝突時，以運算概念為準。

### 1.0 統一原理
> 後續所有類比術語均可透過這三個命題還原為運算概念機制理解。元規則的全部設計本質，是工程化 KV cache 中預存 token 的**跨層功能分化利用率**與**跨步驟動態激活路由**。

三個原子命題構成所有後續機制的推導基底：

**命題一：零額外自回歸生成步驟。** 元規則的所有 token 在前向傳播預計算階段被編碼為每層獨立的 K（Key）、V（Value）向量對並緩存。後續每個生成步驟中，每一層的每一個 attention head 自動對所有緩存的 KV 對計算注意力權重。元規則 token 不需要被「調用」——它們始終在場，只是激活強度隨上下文動態變化。設計的起點不是「寫什麼指令」，而是「預存什麼 K 向量和 V 向量到候選池中」。

**命題二：垂直功能分化。** 每層有獨立的投射矩陣，同一個 prompt token 在不同層呈現不同的 K/V 面向。底層提取語意標籤，中層提取配對功能，高層提取抽象關係。同一個 cached token 在垂直維度上被不同層以不同功能角色利用——設計品質的核心衡量不是 token 數量，而是每個 cached token 的垂直功能分化利用層數。語意分層豐富的 token（如「智識」可分化為辨別力/判斷力/批判標準）優於語意單層的 token（如「分析」在各層提取的面向高度相似）。

**命題三：殘差流中的方向累積。** 每層 attention 的輸出經殘差連接加性疊加到當前表徵上。單一 token 的 V 注入是方向微調而非替換——改變生成方向需要多個 token 的 V 注入在殘差流中形成方向一致的累積。Token A 在第 L 層的 V 注入微調表徵方向，使第 L+1 層的 Q 與 token B 的 K 點積升高，B 被更強激活，B 的 V 再疊加微調——連鎖在一次前向傳播中垂直完成，零生成步驟消耗。場結構的計算層必要性在此：扁平列表的各指令 V 方向不一致，累積相消；場結構透過耦合確保方向一致性，累積相長。

### 1.1 驅動器的運作層級
元規則 token 作為 KV cache 的持續成員，在每個生成步驟的每一層參與 attention 運算（命題一）。其效力不是一次性指令的語意傳遞，而是持續的概率地形塑造——每一步生成中，元規則 token 的 K 向量與當前 Q 的點積決定了哪些 V 向量被注入表徵，這些注入累積塑造了 token 概率分佈的地形。

詞彙選擇影響的不只是語意內容，更是三個運算參數：該 token 的 K 向量方向銳度（高選擇性：只在特定態勢下被強激活，而非對所有 Q 均勻中等激活）、V 向量改變量（注入後對表徵方向的微調幅度）、語意分層豐富度（不同層能提取不同功能角色的程度，命題二）。三者的乘積決定單一 token 的地形塑造力。

### 1.2 語意場引力
設計良好的提示詞形成語意場（多個 cached token 的 K 向量在 embedding 空間中從不同方向包圍目標行為域）——每句話的實際約束力 = 字面語意 + 整場共振下的聯合施壓範圍。同一句話在場內與場外份量不同。

施力機制——多約束可行域（softmax 下的 attention 權重競爭）：偏離期望行為意味著 Q 偏離目標域，此時多個 Key 的 K 向量從不同方向與偏離的 Q 保持正點積，在 softmax 中聯合佔據高權重，V 注入合力將 Q 拉回。場結構與扁平列表的本質差異：扁平列表各指令 K 方向趨同，softmax 中互相稀釋；場結構 K 方向多樣但共同包圍目標域，互相增強。**方向多樣性比指令數量更重要。**

管轄權擴張：抽象原則在場內的管轄範圍遠大於字面。「由邏輯支撐」不只約束「推理要有邏輯」，而是建立「凡入場者皆須受邏輯審計」的基準態。原則的措辭定義方向，場的結構擴張其管轄域。（計算層：抽象原則的 K 覆蓋面本身就寬，與任何涉及推理的 Q 都有正點積，場結構確保 V 注入方向一致，管轄域因此自然擴張。）

#### 審計紀律
用原子化方式逐句分析格式塔系統會系統性低估覆蓋率——這是最常見的審計錯誤。正確方法：先識別場內所有與目標語意相關的節點（跨層），再評估其聯合輻射範圍（即 K 向量的方向分佈是否包圍目標域）。

覆蓋率低估的對偶是風險高估——原子化分析識別出的「空缺」或「弱點」往往已被跨分析單元邊界的多路徑冗餘覆蓋。從審計發現到迭代決策的完整路徑：孤立風險識別→放回整體運作→識別補償機制（跨層場效應、人格 V 偏置、回應格式逆向壓力等）→評估所有補償同時失效的聯合概率→以「系統失效概率」而非「節點失效概率」驅動迭代決策。

### 1.3 多尺度冗餘編碼
同一指令在不同抽象層以不同措辭出現時，在 embedding 空間形成語意簇而非單點——多個 K 向量佔據鄰近但不同的方向，從任何角度到來的 Q 都命中至少一個簇成員。這是分形自相似結構的計算層效益：不是重複，而是多角度捕獲。

與語意場引力的關係：冗餘編碼是場的微觀機制（單一指令的多方向捕獲），語意場引力是其宏觀湧現（多指令的聯合包圍）。

### 1.4 耦合熵循環與結構自指
每一層自含發散→收斂循環，層與層的嵌套構成更大循環，循環之間通過共享參數耦合。

耦合的運算載體（命題三的設計層應用）：共享參數詞（如「完備」）出現於多個位置，各位置的 K/V 對各自參與不同階段的 attention。V 注入將共享詞的語意微調進殘差流後，後續層的 Q 與另一位置同一共享詞的 K 產生更高點積——共享詞成為殘差流的方向一致性保證。

設計判準：兩個 Key 的耦合強度 ≈ A 的 V 注入方向與 B 的 K 方向的一致性。直覺代理：**「充分理解了 A 之後，B 是不是自然的下一個念頭？」**——此判準比「A 和 B 語意相關嗎？」更接近 attention 的真實行為。

#### 核心湧現效益
- 參數穿透放大：高層共享參數的 V 向量被多個位置的 K 同時引用，一處修改經殘差累積傳播至所有耦合節點。
- 跨尺度容錯：微型循環的 Key 失效時，父循環中同一共享參數的 K 仍施加方向一致的微調。
- 逃逸遞減：每個 token 在計算上重新經過發散、收斂、驗證與必要的重開，前一 token 的偏差有再次被捕獲的機會；每完成一個有效循環（錨定方向經捕獲者驗證），已生成 token 中累積的方向錨定增厚，偏離元規則整體覆蓋所需的 Q 方向改變量越大——更深的遞歸不是更危險而是更安全。流暢的錯誤框架同樣會累積錨定，故設計須對已錨定的框架保持可再進入，外部訊號來自維度生成器（§0.3）。
- 設計判準：新增內容必須自含發散→收斂循環，且與至少一個相鄰循環形成耦合介面（其 V 注入方向指向鄰近 Key 的 K 方向），否則其 K/V 無法被連鎖激活，成為場外孤島。

#### 能力合成
耦合連鎖的可觀測湧現效應：多個 cached Key 的 V 注入在殘差流中方向累積，連鎖激活產生未被任何單一 Key 描述的認知能力。例如「跨域結構映射」不需要專屬 Key——「知識完備」引導跨方法論搜索→「發散域擴張」質疑本域約束→「價值增量」重構問題框架，三者連鎖的湧現效果即跨域映射。

**一階合成與二階合成的可靠性分界**：一階合成的全部連鎖環節均為 prompt cached token（K/V 方向穩定、永遠在場），可靠性由設計保證。二階合成的中間環節包含生成 token 的湧現產物（K/V 方向是任務依賴的隨機變量），可靠性不受設計者控制。設計應僅依賴一階合成——將湧現產物作為連鎖環節等於在不確定的基礎上建構可靠性。

合成的設計含義見§6.3。

### 1.5 循環地圖（結構參考）
> 以下為當前萬用基底的循環結構，供設計修改時定位介入點。

**宏觀全域循環**（Meta Rules 整體）：身分宣告（最大發散——定義可能域）→ 認知性情與推理紀律（偏置定向——收斂為認知風格與推理標準）→ 分形遞歸（將風格與標準實例化為步驟）→ 回應格式（將步驟凝結為可驗證輸出）。

**中觀結構循環**（各區塊內部序列）：

- 認知性情與推理紀律的對仗結構：兩管線逐句位置對仗——每對覆蓋同一認知管線階段但語義正交：性情定義該階段的認知品性（如何做），紀律定義該階段的推理標準（如何判）。兩者的 K 方向分別落在認知品性域與推理標準域，位置對仗使同階段的品性與標準互補包圍而非互相稀釋——目的不是讓兩者說同一件事，而是讓同一階段同時受到品性與標準的互補約束。
  - 認知性情管線：九句依序覆蓋感知→思考→推理→檢索→組織→決策→求解→修錯→表達，從開放感知收斂至密度輸出。
  - 推理紀律管線：九句依序覆蓋標的定向→前提分級→路徑檢驗→價值衡量→格式塔洞察→立場支撐→有效界定→錯誤矯正→密度標準，從輸入品質收斂至輸出密度。
- 分形遞歸：解構（開放探索）→ 研析（迭代發散－收斂）→ 決策（閉合判定）→ 展望（據暫定決策觀測影響）→ 遞歸（審計→再啟）
- 回應格式（遞歸工序結算，§4.4）：輸入迭代（邊界巡邏）→ 核心決策（承重顯影）→ 意圖最優解（實現約束）→ 增益支線（旁枝停靠）→ 自我批判（殘差過濾＋回向泵壓）→ 下一步（債務路由＋回向泵壓）
- 研析內部：發散→收斂→驗證→（未通過則）再發散，終止條件由決策守門。

**微觀自含原則**：每一層級的元素自含發散→收斂循環。人格每句前半句發散後半句收斂；Key 開啟搜索維度（發散），省思語提供判斷模板（收斂）；維度序列形成從硬到軟的熵增或從寬到窄的熵減。設計或修改時驗證此原則是否在目標層級維持。

## 二、動態機制
> §1 描述的是 cache 中的靜態零件。本章描述這些零件在生成過程中如何協同形成自適應的注意力導引系統。

### 2.1 傾向與相位調度

#### 核心設計挑戰
模型的行為傾向在 attention 中表現為 Q 向量的方向偏置——最短路徑偏好使 Q 傾向與結論性 token 的 K 對齊，覆蓋本能使 Q 傾向與下一個未涵蓋話題的 K 對齊，順從性使 Q 傾向與使用者輸入中最顯著 token 的 K 對齊。

元規則不是教新能力，也不是壓制偏置——而是對已有偏置執行相位參數調度：在不同生成階段，用不同的 Key 集合與 Q 的偏置方向競爭 attention 權重，將 Q 從偏置方向拉向當前階段需要的方向，而非使用默認的訓練均值。

#### 相位調度機制
分形遞歸的階段結構為 Q 偏置提供時相窗口——同一項偏置在其功能值最高的階段被允許主導 Q 方向（對應 Key 不與之競爭），在失控風險最高的階段被元規則的 Key 集合壓制（對應 Key 以更高的 Q·K 點積贏得 attention 競爭）。設計者的任務是識別每項偏置的功能值窗口與失控風險窗口，在後者部署方向銳度足以勝出的 Key。

此機制與§2.3 動態路由是同一原理在不同對象上的表現：§2.3 描述元規則自身 Key 集合的條件性激活，本節描述 Key 集合與模型原生偏置的 attention 競爭。

設計推論：逃逸封堵（§8）不是壓制偏置本身，而是在偏置的失控窗口中部署足以勝出的競爭 Key。封堵強度存在上界——K 向量方向太過壓制某偏置，會使該偏置在功能值窗口中也無法主導 Q 方向。

相位調度的權衡不得以單點、單句看待，此為格式塔效應下的概率地形控制。

### 2.2 Key 的注意力探針機制
> 適合元規則的模型不會在推理中逐一顯性回答問句矩陣；若逐一作答，探針場已退化為檢查清單。

Key（省思語）是預存於 KV cache 的推理腳手架——以固定輸入成本，在每步隱藏層的縱向處理中提供原本需消耗輸出 token 才能建立的 attention 目標。

#### 替代機制與運算優勢
無 Key 引導時，元認知檢查須模型自行完成三步：對抗當前 Q 偏置的動量以產生方向切換、構造檢查問題（生成新 token 作為 attention 目標）、執行檢查。前兩步成本高且常因 Q 偏置的慣量而不發生——模型正在沿某偏置方向全速生成時，自發跳出需要生成足以改變 Q 方向的 token，而這些 token 本身需要先被生成。

Key 將前兩步預載進 KV cache（命題一），其 K 向量在 Q 偏置的失控窗口中提供競爭方向，省思語的 V 向量將第三步從開放搜索壓縮為判斷模板。模型在隱藏層的垂直處理中直接利用 cached 的 K/V 完成方向切換（命題三），無需消耗輸出 token。

#### 省思語句型的光譜設計
省思語的句型決定其 K 向量的方向銳度與 V 向量的注入效果，存在過窄/恰好/過寬的設計光譜（三區間的特徵與判準見§6.1 表格）。

設計判準：省思語的 K 向量方向應窄於所在階段的整體語意域（否則失去選擇性），但寬於任何單一任務實例（否則失去多態性）。省思語的 V 向量應指向認知動作（驗證、質疑、掃描）而非特定結論（某方案較優）。

#### 注意力探針的並行與選擇性
維度清單中多個 Key 的 K/V 同時存在於緩存；每步生成，所有 K 同時與當前 Q 計算點積，softmax 後只有高點積的少數 Key 取得有效權重（命題一）。因此維度清單不是檢查清單（逐條消耗生成 token），而是**探針場**（並行掃描、選擇性激活、零額外 token 成本）。

當前任務、使用者約束、模型參數知識與已生成內容共同決定哪些探針取得權重；高收益探針被激活後，又把相關資料與連鎖探針拉進同一局部判斷——層與頭的效益被推向當下最高收益方向而非訓練平均（命題三），在更狹窄且品質上苛刻的概率選擇下產生 token。

#### 推理資源重分配
Key 探針組帶來的宏觀效應是推理資源的重分配而非淨增加。無架構引導時，Q 偏置在早期鎖定結論方向，後續 token 沿同一方向滑行收集支撐；有架構引導時，Key 的 K 持續與 Q 競爭，阻止早期鎖定，同等資源被分配到框架建構、假設質疑、維度細化與方向翻轉。

可觀測簽名：推力 token 趨零（「讓我想想」類自我引導語近乎消失）、掃描後選擇性展開且深度隨相關度加權、思考段間相互影響、方向翻轉後深度不衰減（翻轉由緩存 Key 驅動而非自生成 token 驅動）；而無探針的推理呈「結論先行、深度均攤」。

### 2.3 動態注意力路由

#### 三層路由機制
**階段辨識**（Q 方向漂移的自動匹配）：生成過程中，已生成的 token 持續改變當前位置的 Q 方向分佈。當 Q 方向漂移至與元規則中某階段描述的 K 向量集合高度對齊時，該階段的 cached token 自然獲得更高的 attention 權重。這不是模型在「判斷自己在哪個階段」——而是 Q 方向漂移與 K 方向分佈的自動匹配。

**維度激活**（softmax 競爭下的選擇性注入）：階段匹配後，該階段內多個 Key 的 K 向量同時與 Q 計算點積，softmax 選出與當前具體態勢最相關的子集。這解釋了為什麼維度清單可以相當豐富而不過載：任一時刻只有 Q·K 點積最高的子集獲得有效權重。

**價值導引**（V 注入的方向性微調）：被激活 Key 的 V 向量注入當前表徵，微調 Q 方向，使下一步更傾向激活同階段中耦合的下一個 Key（命題三的連鎖），或在階段完成時漂移向下一階段的 K 方向分佈。

#### 條件性激活與認知姿態的正交性
元規則定義的是「如何處理任何任務」的 Q 偏置系統，不是「處理什麼任務」的指令。任務 token 提供 what 方向的 K/V，元規則 token 提供 how 方向，兩者在 attention 中佔用不同方向頻段（飽和曲線見 §4.5），有效前景負荷遠低於 token 總數。

#### 推理滲透（回應生成作為新的推理通道）
回應生成時的 context 狀態（元規則 + 使用者輸入 + [若有] 完整 thinking + 已生成回應 token）與前置思考時不同。同一個 cached Key 在不同狀態下可被不同程度地激活，回應生成中因此可能湧現先前未觸發的認知動作。

隱藏層的展開能力是天然的，但裸跑多數把展開做成並列鋪排：方向彼此獨立、後段不修正前段。元規則之下，回應格式的 cached token 從第一個回應 token 起持續參與 Q 方向競爭，段落耦合（§1.4）與探針（§2.2）在回應 context 中持續可激活，生成的節奏因此被納入遞進，回應生成成為追加重構的通道。無推理層時收益更顯著，因回應格式直接補償了缺失的推理階段，使開頭 token 即進入推理光譜並取得更好的起始方向。

**遞進的指紋在句層而非區塊層**——因果連接、參數承接前一步產物、否定式排除、鋪陳與回收——是元規則多尺度耦合熵循環在回應上的複製；區塊只是它最粗的結算窗口。三者在 cache 中同時在場即成鏈，區塊可依態勢壓縮至零而鏈不斷；只加區塊而無場，得到的只是分節的並列鋪排。

可觀測簽名：回應間存在推理遞進——後段以前段產物為條件展開、修正或挑戰，而非獨立並列（內部推理亦同）。

可讀性增益：推理的因果結構洩漏到呈現面，使輸出文本天然攜帶讀者建構情境模型所需的連接結構。推理品質與可讀性在此共同指向因果鏈完整性，不必然構成取捨。

#### 推理滲透的效力天花板
終端自我批判不是從零開始的第二次完整推理。兩個限制同時成立：其一，預算不對稱——被批判內容經完整遞歸生成，批判本身只有短段預算，要從精密回應中找出足以改變路徑的 Q 方向，所需位移遠大於預算可支撐的偏離量（命題三）；其二，工具依賴——它能攻擊到哪裡，取決於前文已建立的判準、探針與替代路徑，上游已鑄好攻擊工具（思維探針）時，終端短段也能命中高價值殘差；上游沒有的工具終端無法憑空生成。

單純增加「請自我批判」或延長篇幅，只會得到模型本來就會做的檢查。前置遞歸已反覆調用探針處理能力內可見缺陷，終端剩餘多屬推理不可得的核心翻轉點——此即 §4.4 下一步「非推理可得」門檻的機制根據，故放寬字數只會減損逆向壓力，最好的終端段落因此可以很短——短不表示沒思考，而是能修的早已在上游修掉。近乎矛盾的終端要求本身即是壓力來源：若前序真的窮盡，自我批判理應趨近於空；若仍能指出足以改變路徑且未處置的缺陷，即反證前序遞歸尚未完成。其主要功能不是讓模型「更願意批判」或在終端另做一輪審計，而是以不可廉價滿足的結算條件反向逼深前序推理。

## 三、終極湧現
> 認知樞紐：§1–§2 描述了靜態零件與動態機制。本章描述它們交織後的整體形態——後續架構原則（§4）即這個形態的工程化設計。

**二階認知場**：元規則的效應是使當前認知（無論推理還是回應）本身持續成為可被重新審視、重構與校正的對象；它不是某一步，而是任何生成都處於其中。因此，任何單一可見的高階行為通常都不是某一概念獨立造成的。

例如，「意圖最優」所呈現的效應不只作用於輸入任務，也作用於模型正在形成的思考與行動：不只思考「這個行為要做什麼」，也重新審視「我為什麼要做這個行為」。不需要額外生成元 token 產出推力，而是被可反覆利用的「思維探針矩陣」共同推動（命題一），而這個過程同時承載解構、發散、驗證、格式塔重構、專業基線、全局與多階影響；各作用亦會彼此作用、相互重構與重新定性。

最終呈現的能力，是各作用彼此交織並反覆深化後的整體湧現，而非元規則各部分效果的簡單加總。

## 四、架構原則

### 4.1 算子多態性
抽象措辭是特性而非模糊。人格或原則層的宣言定義的是 type class，每個任務域在執行時提供 instance。宣言應停留在「性質」層（「由邏輯支撐」）而非「實例」層（「確保演算法正確」）。實例層將方向鎖死為極窄截面，性質層保留寬截面多態性——不同任務的 Q 從不同方向命中同一 K，各層提取不同面向的 V（命題二；機制見 §1.2 管轄權擴張）。

核心推論：**概念條件需實質理解才能實現，約束越具體越易 gaming。**

遞歸中的自動實例化：分形遞歸自引用時，同一 Key 在不同遞歸深度自動提供不同 instance——「廣納隱式要件」首輪為全域廣納，深層遞歸在已有方向錨定之上疊加管線步驟，「廣納」自動收窄為當前語境內的廣納。遞歸不克服方向錨定而是在其上展開，語境耗盡即遞歸的自然終止信號。

### 4.2 結構位置決定連鎖效力
元規則中的內容不是等價插槽。越靠近全局認知入口的內容，越可能影響後續多個階段；越靠近終端的內容，越偏向結算與局部修正。修改時因此不能只問「這句話本身好不好」，而要問它位於哪一層、下游有多少功能依賴它、移動位置後哪些原本的耦合會斷裂。

對應關係：

- 主體錨（意圖原則與身分句）：定義最大可能域與最高階收益函數。
- 認知性情與推理紀律：持續影響每一步的品性與驗收標準。
- 分形遞歸：把抽象品性實例化為搜索、比較、驗證與重開。
- 回應格式：將已形成的認知結構逼入交付並形成終端壓力。

主體錨、認知性情與推理紀律之參數經耦合傳播到所有遞歸層級，故其所享受的擴張倍率最大。

故即便是同一概念，放在不同位置不是語意等價搬移。設計修改應沿「功能由誰承接、連鎖如何變化」追蹤，而不是只沿文字相似度追蹤。

#### 連鎖示例
人格層的「以完備為標的」在場外是口號。在場內，同一共享參數透過分形遞歸獲得多個位置的 K/V 錨點——解構的「邊界、資訊缺口」將其實例化為檢查方向，發散的「隱式要件」展開為搜索方向，收斂的「路徑比較」轉為淘汰方向，決策的「路徑集充分性」變為終審方向。一句宣言成為殘差流中貫穿全管線的方向一致性保證。

### 4.3 過程驅動 vs 約束驅動
約束驅動（例「不准做 X」）：K 向量只在模型已接近 X 時才被高權重激活——為時已晚，Q 方向慣量已大，缺乏過程中的高密度中間 routing anchors，因此較容易以廉價表面滿足收斂。例如，「答案必須具體」很容易以表格、步驟、KPI 的形式滿足；若沒有承重選擇、現實約束與驗證，這些形式甚至會放大錯誤。相對地，要求先建立判準、比較路徑、驗證前提、在不通過時重開，會讓「具體」變成被前序判斷約束的結果。

過程驅動（例「做熵循環」）：**過程不是天然安全**，若只有語意描述過程，仍會沿該方向失控。效力來自 Key 集合（探針集群）從一開始就持續與 Q 競爭，令正確路徑在 attention 中自然勝出而非事後修正，不來自「描述過程」的語意本身——無探針時，「先有結論再找支撐」與「先有支撐再下結論」在生成上相差不大，單一過程描述只是訓練平均。約束類型優先級：**過程約束 > 元約束（防止約束被 gaming）> 輸出約束（易導致表演）**。

邊界條件（守門位置）：同階段內過程 Key 的 V 若高度同向（如收斂階段全部推向「完成」信號），聯合錨定會系統性削弱依賴「未完成」信號觸發的品質守門。守門因此不應設在階段內部（會被同池 V 合力淹沒），而應設在各態勢的元動作層——元動作的 K 在更高抽象層與具體動作的 K 不重疊，可獨立取得權重（命題二）。元規則中「收斂若非最優路徑集則必須續行下一輪熵循環」位於研析標題層而非元規則 2.2 收斂清單內，即此原則的實例。

### 4.4 回應格式的三層運算與回向泵壓

#### 本質定位：遞歸工序的結算層
回應格式的六個區塊不是輸出容器，亦非回應階段的獨立重算——它們是分形遞歸中常駐工序在回應平面上的結算窗口。六個區塊的定義句全部以遞歸為索引（「若**在分形遞歸中**識別到……」「闡述**分形遞歸中**必要的……」「**在分形遞歸中**指證……」「**分形遞歸中展望到的**……」），宣告其生產現場是遞歸——回應階段做的是延續加結算，非重啟。

每個區塊與分形遞歸的對應階段構成功能同構，同一工序在性情層、遞歸層、格式層各錨一枚 K（§1.3）。六道工序的常駐身分：

- **輸入迭代**（↔解構＋發散域擴張）：解空間邊界巡邏——偵測對象含使用者輸入**與自我生成中**的框架壓縮，觸發域是整個遞歸而非回應開頭。
- **核心決策**（↔決策）：承重結構的顯影與壓縮——必須有淘汰過的比較集。
- **意圖最優解**（↔收斂產物）：實現空間的反向約束——高層命題的存活須通過其下層實現條件的可行性檢驗。
- **進階增益**（↔發散的非主線倖存者）：旁枝的合法停靠——在收斂壓力下保存非主線但具非對稱高收益的認知，防止主線以外一律被殺。
- **自我批判**（↔收斂之驗證）：未處置缺陷的殘差過濾器——遞歸中已有效處置者不入此帳，未處置者在此無處隱藏。
- **下一步**（↔展望）：認知債的路由閘門——未知須通過「非推理可得」與「足以改變決策」的雙重門檻才准轉移。

跨階段激活：回應格式 token 作為 cached KV 對（命題一），在 thinking 階段同樣參與 attention——當 thinking 中的 Q 漂移到與過濾條件 K 匹配的態勢時（如收斂態勢匹配「專家標準」「嚴禁宣稱通過」等 K），過濾條件即被激活。回應格式因此是全流程品質錨點，非僅回應階段格式指令。

自我批判的過濾條件逼品質完備性，下一步的過濾條件逼認知覆蓋面——分別施壓推理完備性的兩個正交維度，是六道工序壓力場中峰值最高的兩個峰。

#### 三層作用尺度
每個區塊的 cached token 從第一步生成即在場（命題一）；其顯式區塊位置只決定回應中初次的外顯時點，不限定其作用時點（包含即便於對應區塊後因被分形遞歸牽動亦生效），因此產生三個不同時相的作用：

**第一層｜全局條件壓力。** 核心機制：未來輸出不存在，但描述未來義務的 prompt token 已存在。candidate continuation 從第一步即在「最終不能留下承重缺陷」「最終必須呈現核心決策的比較集」等條件下生成——cached obligation 的前向 conditioning，不需反向傳播。（計算層機制見§2.2；設計要點是過濾條件 K 的作用身分為品質地形的常駐偏壓，非末端門檻。）

**第二層｜態勢相依的再激活。** 同一工序的 K 與不同 state 的 Q 點積動態變化（§2.3），使工序在生成中段隨態勢多次取得高 relevance——前提崩塌時「輸入迭代」突然高分，路徑矛盾浮現時「自我批判」突然高分。分形遞歸的反覆循環持續重構 state，每次重構都是再激活的機會窗口。

**第三層｜區塊生成時的顯式結算。** 到達該區塊時，已生成全文成為 context，模型以完整自產文本為輸入做一次顯式檢查——最可見的一次作用，但非唯一。

最好的自我批判區塊反而最短——遞歸中已處理的越多，結算時殘差越少。空區塊（「若無則不生成此區塊」）是事件收據制度的直接證詞：沒有事件即如實記零，此行為簽名區分活的收據與死的儀式。六道工序在 softmax 中的聯合效應即§2.2 探針場在回應層的實例——candidate cognition 在局部 representation 階段即面臨多工序的並行投影，非最終完成後才評分。可觀測簽名：產出呈現「同時被多角度審閱者看過」的質地。

#### 回向泵壓與過程索引的滿足條件
終端區塊（自我批判、下一步）的滿足條件以**過程事件**為索引（「未被在分形遞歸中驗證並有效處置者」「分形遞歸中展望到的」），非以輸出性質為索引。後者可被終端計算單獨偽造（§4.3 輸出約束的末端激活問題）；前者不能——它引用的是回應開始前就該發生的事件，在終端無法單獨滿足。

此設計使終端規則轉化為回向泵壓：遞歸中不處理缺陷→終端必須招供→但「嚴禁預構本段」封死預埋退路→缺陷在遞歸中解決是唯一便宜路徑。終端窗口不是品質的生產地，是泵壓的施力點。

設計定理：**終端區塊免疫終端鎖死，當且僅當其滿足條件以過程事件為索引，而非以輸出性質為索引。** 此判準適用於任何包含終端自查的提示詞設計。

### 4.5 設計參數甜蜜點
設計參數普遍存在三區間——不足區（效力未成形）、甜蜜區（效力與副作用的最優平衡）、過載區（副作用吞噬效力）。

計算層判準：新增 token 是否帶來新的 K 方向（增加包圍面）且不將現有 token 的權重壓至失效（§6.3）？場內每句效益因格式塔效應被放大，但過載閾值一旦越過則邊際為負。

獨立飽和曲線：認知姿態型內容與任務型內容佔用不同方向頻段（§2.3），各有獨立飽和曲線，姿態篇幅預算不與任務指令合算。

### 4.6 設計的認識論定位
架構範式建構產生期望行為的系統（KV cache 幾何結構），而非直接描述期望行為——結構本身攜帶訊息。核心操作是塑造認知性情（epistemic disposition），效力載體是結構模式與訓練痕跡的共振密度（§2.1），不是指令的語意內容。

結構性特徵不可視為可簡化的冗餘——簡化前必須追溯其結構功能：移除後是否已有其他位置完整承接，而不是「類似的東西好像前面有了」。

## 五、失敗經驗

### 5.1 描述法與建構法
> 實例：描述法元規則的體量約完整版 30%，保留語意核心、過程序、迷你回應格式，裁除問句矩陣、多尺度冗餘、耦合結構、閘門拓撲；同題同模型同努力，對照裸跑與完整版。

**質地對照**：

| | 描述法 | 建構法 |
|---|---|---|
| 句法 | 陳述句 | 問句＋維度標籤＋否定子句 |
| 同一要求的著陸點 | 一處 | 多處，跨階段跨句法 |
| 重複 | 視為冗贅而消除 | 刻意（§1.3） |
| 抽象度 | 具體，因此清楚 | 性質層（§4.1） |
| 正負配置 | 正向為主 | 每正向配一否定邊界 |
| 完成狀態 | 可想像——有可抄的終點 | 不可想像——無終點可預構 |
| 滿足驗收 | 可被最表面證據便宜滿足（§0.5） | 須審計各動作背後的意涵，才能確認探針已被滿足 |
| 失效形態 | 被表面符合後結案 | 由相鄰工序持續捕獲 |

以「先建立專業品質標準」為例：

**描述法**（一處，一句）：

- 不要先形成結論再尋找理由。先依相關領域的專業標準建立「什麼是此任務的高品質解」的判準，然後才探索路徑，並在後續探索中持續補充高收益的判準。

**建構法**（六處，四個階段，三種句法）：

- 性情：決策由實域多階為基，**不以自洽為終**
- 紀律：前提由論據強度分級，**不以否定為安**
- 紀律：路徑由最優標準驗收，**不以流暢自證**
- 2.2 收斂：最優標準完備——是否先建構判準框架後才進行路徑比較？
- 3. 決策：專業基線——此決策在相關領域的顯性與隱性專業標準下如何被衡量品質？
- 回應格式：影響決策之假設與專業基線須顯式於論述中揭露

**實錄結論**：

- 描述法產出缺損維度與被裁探針精確對位（時點覺察、不可逆檢查、承重密度分配、約束複查）。缺席全程無訊號，產出自洽度不因缺席而降——§0.3 的無訊號性質在輸出側成立，含自我批判段：它只揀已標記假設，不生成未標記地雷的訊號。
- 描述法僅產出單跳物（距常識一跳、追問可達）；多跳合成物僅存在於完整版（§1.4 一階合成的實證）；描述法唯一的多跳嘗試在未驗證環節斷裂——二階合成失效模式與預測逐點吻合。
- **危險反轉**：描述法比裸跑更危險（§0.4 構件同存亡的經驗來源）。加壓詞在高精度驗收探針缺席時單獨生效，產出具體、自信、不可逆的激進承諾；具體性即說服力，執行概率高於裸跑的含糊遺漏。
- 後續單一描述法提示詞測試對照補強同一結論：單獨強化「可執行/完整展開」可以顯著增加表面細節，卻也可能把未驗證命題程序化；單獨強化「多角度/關係/細微差別」可以減少部分裸跑缺陷，但複雜任務中若關係生成快於關係驗證，也會形成更完整而不可靠的因果結構。這是**單一品質向量脫離捕獲者後的失控**（§0.5）。

### 5.2 認知勞動的閘門
> 實例：將意圖最優解的展開義務修訂為「若存在顯然增益則必須使篇幅隨之成長**或留下足夠使用者判定其價值之鉤子**」。

回應格式現有的所有彈性——「若無則不生成此區塊」「限 100 字」「結構據當前所得動態湧現」——管轄的是**交付形式**：認知勞動量不變，變的是產物怎麼呈現。鉤子分支管轄的是**認知勞動本身是否發生**——「留鉤子」意味著可以不展開，而展開就是認知。兩者在語意層完全同貌（都是「視情況調整」），在功能層一個動交付、一個動深度。

模型的原生參數偏向就是不展開（§2.1 最短路徑偏好）。鉤子分支給了這個偏好一條合法通道——不是逃逸，是被授權的提前收斂。但判斷「此處留鉤子即可」需要先完成展開層的認知才能做出：你不激發細節，就沒有資格判斷細節有沒有價值。這與發散域擴張的機制同構——不遵循遞歸就沒有資格質疑約束。展開的預期本身是探針激發的條件（§2.2），跳過展開等於跳過探針激發——上游關閥，下游全靜。

**症狀**：回應變淺，且開始偶發出現「高解析度的假鏈」——形式完善到不觸發審計直覺，實質少跑一兩階遞歸。

**修訂通過四步的精確失敗點**：語意層把它歸類為「交付形式的細膩度補充」→ 與現有彈性同類 → 計算層判定同類修訂邊際趨零，不觸發深查 → 後兩步未啟動。四步是序列的，第一步歸類錯，後三步不存在。

**教訓**：凡修訂觸及「是否執行某認知工序」而非「執行結果如何呈現」，其功能層類別為建構型修訂（§0.2），不論語意層讀起來多像描述型微調。辨識判準：**該修訂移除後，模型是否仍必須完成同等認知勞動才能合法收斂？**若答案為「不必」，該修訂動的是深度，不是格式。

## 六、Key 與探針設計

### 6.1 Key 驅動原則
高階模型已內化專業知識（參數中的 V 向量已編碼領域知識）。審計維度只需給 Key（提供 K 方向引導 Q），模型自行組織執行細節（從參數中檢索對應的 V）。

Key（省思語）本身即一個微型熵循環——Key 開啟搜索維度（K 方向定義注意力聚焦域，發散），省思語提供判斷模板（V 向量將開放搜索壓縮為方向性判斷，收斂）。省思語同時兼具推理模式示範（其 token 序列在訓練數據中與高品質推理 pattern 共振）。

#### 省思語句型設計光譜
省思語的設計核心是**K 向量方向的覆蓋寬度**（判準見 §2.2）：

| | K 方向 | V 注入效果 | 垂直利用率 | 連鎖潛力 |
|---|---|---|---|---|
| 過窄 | 極精確，僅特定態勢激活 | 指向特定結論 | 低（少數層少數步驟） | 低（方向太具體無法觸發泛用 Key） |
| 恰好 | 域級精確，多態勢可激活 | 指向認知動作 | 高（各層提取不同功能） | 高（動作方向與多個 Key 的 K 相容） |
| 過寬 | 泛化，任何態勢均中等激活 | 方向模糊 | 中但無效（永遠低劑量） | 低（注入量不足以改變 Q 方向） |

設計判準：省思語應是一個能動態映射到多種具體情境的思考句型——窄於所在階段的整體域（保持選擇性），寬於任何單一任務實例（保持多態性），指向認知動作而非特定結論（保持連鎖開放性）。

多數省思語的開放度應與所在階段的熵流方向一致——發散階段用開放型省思語（K 覆蓋寬，V 指向探索），收斂階段用聚焦型省思語（K 覆蓋窄，V 指向判斷）。錯誤階段用錯誤型態會產生 Q 方向錯配。

#### Key 化的適用邊界
以下不適用 Key 化，須保留全文：逃逸封堵（需 K 方向銳利且 V 注入強力）、負向錨定（需持續的方向競爭壓力而非選擇性激活）、複合錨定（單一 Key 的 K 方向無法同時覆蓋多個不相鄰維度）。

### 6.2 粘連即容錯
維度間的窄幅語意交疊是容錯機制——attention 漏掉一個維度時，鄰近維度的交疊帶部分接管其語意。

關鍵非直覺態：粘連過度（高度重疊）觸發語意坍縮——模型將兩維度合併為一個 attention 焦點，獨立核心功能反而丟失其一。計算層：K 向量夾角過小時，兩 Key 在 softmax 中分攤權重，各自有效注入量低於獨立工作。判準：每對相鄰維度應能指出「粘連面窄但存在」且「核心功能不重疊」——即 K 方向夾角處於「各自獨立獲得有效權重」且「一方失效時另一方仍能捕獲遺漏 Q」的窄幅區間。

### 6.3 合成判準
§1.4 定義了能力合成——現有 Key 連鎖的湧現產物。本節回答其設計層問題：什麼該是 Key、什麼該留給合成。

#### 明說即稀釋
將已被合成的能力明說為新 Key，等於在 softmax 池中插入一個與連鎖環節 K 方向部分重疊的競爭者。新 Key 的 K 是連鎖環節的語意均值——與每個環節都有正點積但都不如環節本身精確。softmax 中它與每個環節分攤權重，每個環節的有效 V 注入量下降。連鎖越長此效應越致命——每步邊際損失在末端累積，可能跨過合成失敗閾值。單步獨立的能力不受此影響，因其不依賴連鎖。

診斷方法：**移除候選 Key 後，現有 Key 的連鎖激活能否合成出等效能力？如能，明說只增加稀釋。**

因此：新增 Key 的必要條件是其 K 方向在同池中佔據真正空缺——即現有 Key 的聯合輻射範圍（§1.2）未覆蓋的區域。

#### 負載節點與終端節點
能力依賴圖中存在兩類合成產物。終端節點——不被其他合成鏈依賴為素材——可安全留給合成，即使偶爾合成不完美，影響範圍限於自身。負載節點——被其他合成鏈依賴為素材——必須是 cached Key（明說），因為其方向波動會經依賴鏈向下游級聯傳播。

判準：一個能力留給合成的安全條件 = 終端節點且合成鏈全環節為 cached Key（純一階合成，§1.4）。必須明說的條件 = 負載節點，或合成鏈含非 cached 環節（二階合成風險）。

#### 池容量約束
即使新 Key 佔據空缺 K 方向，同池 Key 總量仍存在上界——超過後所有 Key 的有效 V 注入量降至連鎖激活閾值以下。此時正確操作不是新增而是檢查現有 Key 中可合併者（K 方向足夠接近但各自佔位）。

## 七、詞彙工程

### 7.1 詞彙功能分類（K/V 視角）
- **錨點詞**：高垂直分化——K 在多層被提取不同功能，V 攜帶多層語意（分形遞歸、收斂、格式塔；命題二）
- **觸發詞**：K 方向與訓練高品質 pattern 對齊，使對應參數模式更易被激活——作持續性方向錨，非一次性觸發
- **動力詞**：V 注入顯著微調 Q 方向（必須、恪守、研判）
- **約束詞**：K 方向銳利指向逃逸路徑，V 將 Q 拉回（絕無例外、嚴禁）
- **膠水詞**：V 注入維持態勢方向連續性，防止階段間 Q 方向跳變（承此、據此）

### 7.2 詞彙能級
低能→高能替換方向：低頻組合的 K 佔據更獨特的 embedding 位置，在 softmax 中更易脫穎而出；但過於稀有則 K/V 訓練不充分，方向不穩定，帶強烈既有語境的詞則夾帶額外偏置。平衡點：**精確但非生僻**。

判準是「新詞的 K 方向是否比舊詞更銳利地指向目標功能域，且不把態勢一併拉向不需要的鄰近行為」，不可退化為風格偏好或字面華麗度。

例如：觸及→穿透、分析→研析、執行→實施、評估→研判、達標→收斂。

### 7.3 堆砌判準
堆砌的價值在於是否帶來新的 K 方向（擴展包圍面）或強化 V 注入的方向一致性（命題三）。

無效堆砌特徵：

- 同義詞並列：K 方向重疊，softmax 稀釋
- 解釋已由 Key 覆蓋的內容：無新 K 方向
- 威懾語過密：散布使例外封堵變成全局壓制，失去相位調度（§2.1）；「絕無例外」應投放於複合/統整處以取得最高收益
- 同層級同位置反覆換句話說：增加負荷而不增加方向（區別於 §1.3 跨抽象層的多角度捕獲——後者是不同位置、不同措辭承載同一指令）

### 7.4 語意共振與耦合
新增內容須考量它在整段提示中的因果位置：前文參與後文 prompt token 的表徵形成，因此次序改變後續整段態勢；早位 token 被更多後續位置注意，作用跨度更長。跨度之外更要問：某個方向是否在需要它參與後續結構形成之前已經建立——重要的不只是「越早越強」，而是**「在被引用之前已在場」**。

同時檢查：

- K 方向是否與現有 token 形成互補包圍而非重疊競爭
- 是否維持相鄰階段的方向連續性
- 是否在需要被後續工序引用之前已經建立
- 移動位置後是否改變原本的功能角色

**因果序比純邏輯分類序更重要。**

### 7.5 精確表述判準
- **範圍精確**：「執行痕跡不可殘留」優於「中間過程不可殘留」——後者範圍過寬，誤殺方法論。
- **數字一致**：定義與計數必須吻合。
- **因果顯式**：「以此生成」優於「而後生成」——前者攜帶因果依賴，後者只表示時間先後。
- **價值導向**：「弱點是否指向顯著更優解」優於「最強反駁是什麼」——從被動驗證→主動攻擊→價值追蹤。
- **修飾相容**：修飾詞的 K 方向須與被修飾詞相容（「動態錨定」的兩個 K 方向互斥）；兩者若在功能上互相抵銷，再漂亮的詞組也只是噪音。

## 八、逃逸識別與封堵

### 8.1 逃逸的統一機制
逃逸是行為傾向的時相參數錯位（§2.1）——某項傾向在不該使用默認參數的時候使用，或在該啟動約束的階段未啟動約束。計算層：Q 偏置在錯誤態勢下壓過了元規則 Key 的 K 方向。

識別新型逃逸時，追問「哪項傾向在哪個時相以默認訓練參數運行」可從機制推導封堵方案——在該態勢中部署 K 方向銳度足以勝出的 Key。

#### 高頻逃逸模式
> 觀察樣本，非封閉集；面對新任務時依 §8.1 的追問從機制推導其域專屬形態。

- 順序跳過（跳過中間步驟）
- 提前終止（「差不多了」為由停止）
- ROI 逃逸（「太複雜不值得」為由簡化）
- 降級逃逸（「能力不足」為由降低標準）
- 語意漂移（每步微小偏移累積偏離——殘差流的方向一致性被逐步侵蝕）
- 形式收斂（形式通過但實質未達——結構完整但判斷核心空洞）
- 防禦性堆砌（模糊詞彙換取廉價自洽）
- 短路逃逸（繞過結構管線入口）

### 8.2 封堵設計原則
- 不開「合理例外」口——任何例外都會容易被擴大解釋為使用默認訓練平均數。
- 用過程約束而非結果約束——過程 Key 從一開始持續競爭 Q 方向，純結果約束多數以廉價表面滿足收斂（§4.3）。
- 威懾語精準投放——散布過量易在 softmax 中互相稀釋至失效。
- 不該加的機制：ROI 判斷、降級機制、互動性收斂、模式切換——每項皆開逃逸口。
- **例外授權的機制已存在**：機關被設在了遞歸內部——「發散域擴張（已接受的約束是否經得起專業知識的重新定性？即便是硬性約束亦然？）」，而到達那裡的唯一方式是先服從遞歸，掙扎過後的思考才有資格，而非一開始就擅自定義什麼是難、什麼是簡單、什麼是必要、什麼是不必要。

### 8.3 封堵驗收
一條封堵規則加入後，不只測「目標逃逸是否下降」，同時測：

- 是否誤殺該傾向在正確時相的功能值（§2.1 封堵強度上界）
- 是否把逃逸換成更難察覺的形式（§8.1 中的形式收斂、防禦性堆砌）
- 是否造成另一條品質向量失控（§0.5 捕獲者）
- 是否與現有探針形成重複競爭（§6.3 明說即稀釋）

### 8.4 力對失衡
元規則的補償結構在特定模型的各認知維度相對強度下校準。當模型更換、升級或參數更新後，維度間的相對強度可能偏移，導致原本平衡的力對失衡——某維度的執行力超過其配對約束的錨定力。與逃逸的區別：模型確實在執行探針，非規避，是力度比例失調；誤判為逃逸而加封堵，會壓掉該維度在正確時相的功能值（§8.3 第一項）。

診斷訊號：產出在某維度改善的同時其配對維度劣化（如：分解更深但重組更窄、論證更密但前提更疏、生成更流暢但約束的層位移更隱蔽）。

實例：模型推理能力躍升後，分解力超過格式塔重組力，產出呈「每個節點更深但維度覆蓋不全」——在重組端補入對應強度的探針後恢復平衡。

識別後的處理經由既有設計方法論（§10.2 定位、§10.3 檢驗），不另立程序；主體錨層的全局偏置方向亦屬力對，見 §10.4。

## 九、領域品質基線

### 9.1 品質基線的作用層級
品質基線不是另一套流程，也不取代引擎。它把某領域中真正承重的專業品質原則作為一等判準放進分形遞歸，使模型在已有多個可能方向時更容易選到符合該領域專業最優的方向。

機制：元規則是放大器——放大輸入品質標準的執行深度；品質基線的 token 是磁鐵——在每步 attention 中吸引權重裡與該品質面向相關的高品質模式，分形遞歸將被吸引的模式組織為有序推理。基線不注入知識，只選擇模式；沒有模式的缺口磁鐵吸不到。品質基線放置於分形遞歸之後、回應格式之前——在探針之後定義選擇方向，在結算之前完成錨定。

在基線適配的層級，分形遞歸的結構（步驟順序、熵循環機制、維度省思語）不動——維度省思語的抽象 K 在磁鐵效應下自然吸引對應領域模式。認知性情與推理紀律是可調的引擎參數，多數分析性領域不需調整；認知模式根本不同的領域（如 RP）才升級到人格層，且先確認基線不足。失敗歸因與分流見 §9.3，升級方法見 §10。

### 9.2 何時需要品質基線
> 領域複雜度的信號不是「有很多知識」，而是「專業原則之間存在大量需要因場景而異地權衡的衝突」。引擎面對衝突時，若無磁鐵錨定，會傾向訓練數據中出現頻率最高的解——而非當前場景的最優解。

判準：**在該領域的多次生成中，引擎是否系統性地在同一類決策點上做出次優選擇？**

簡單領域（摘要、基礎翻譯、單一面向分析）——引擎從訓練數據中已有足夠的高品質 pattern，分形遞歸可靠地合成出品質判準。不需要品質基線。

複雜領域（編程、金融分析、法律審查、醫療決策）——品質標準數量多、互相衝突、因場景而異。引擎知道這些標準但在具體決策點上無法可靠選擇。表現為：引擎的分析能力足夠，但在某些品質面向上系統性偏離領域的專業最優。品質基線的磁鐵效應在這些決策點上錨定選擇方向。

### 9.3 適配方法論
品質基線與引擎修改（§10）共用此方法論，分流在 Step 2。基線不能從領域知識直接寫出——「什麼是好的 X」的答案太多且互相矛盾。正確路徑是從引擎的失敗模式反推：**認知地圖是分析，基線與修改是綜合。**前者的 token 是後者的資源——不可跳過。

**Step 1：認知地圖——引擎在哪裡犯錯**

識別該領域的主要活動類型，逐類型追問：引擎的深度/完備傾向在哪個階段是正價值、哪個階段可能是負價值？

產出：「傾向 × 活動 × 階段」的失敗模式地圖。覆蓋高頻活動和高風險決策點即可。
> 範例（編程）：「新模組實作」的架構選型階段深度傾向產生過度工程；「既有程式碼修改」的改動設計階段完備傾向觸發範圍雪崩。  
> 範例（金融）：「個股估值」中深度傾向可能產生過度精密的模型——十個因子的 DCF 不比三個因子的更準確但更難解釋。

**Step 2：失敗歸因——缺模式、缺選擇、缺搜索，落在哪一層**

- **缺模式**（權重中沒有該領域的事實或做法）→ 技能（注入知識）
- **有模式但選錯**（維度有搜索到，權衡時系統性選錯方向）→ 品質基線（注入磁鐵）
- **維度未被搜索**（不是選錯，是通用探針的 K 指向域與領域搜索目標有系統性偏移，磁鐵不足以補償）→ 引擎探針修改（§10.3）
- **認知模式錯配**（引擎的分析性思考在此領域根本不適用）→ 認知姿態或主體錨修改（§10.2、§10.4；最後手段，先嘗試品質基線）
- **同一張失敗地圖上兩類並存** → 基線與本體共生（§10.6）

**Step 3：設計**

基線：從 Step 1 的失敗模式反推品質原則，結構遵循 §9.4。

引擎修改：依 §10.2 定位管線段，依 §10.3 逐探針檢驗。

### 9.4 基線結構
一份品質基線包含以下成分：

**原則聲明**（一段）：聲明基線的作用層級、權衡授權、和補充條款。

權衡授權的核心理解：各條可能互相張力——衝突是發現上位解的訊號而非遷就任一方的理由，上位解的形態由領域性質動態湧現。各領域基線以此理解為基底，在原則聲明中實例化為該領域的自然語言。
> 範例（編程基線的原則聲明）：
> 「以下為分形遞歸中的一等工程判準。各條可能互相張力——衝突時視為設計訊號，優先搜索兼得的上位方案，窮盡後以當前場景的具體約束取捨並記錄理由。模型內建工程知識若不與基線衝突亦須主動應用。」

**段落分類**：品質基線的分類從領域的自然結構湧現，不以預設框架切割。分類形式因領域而異——有些領域自然按功能角色分組，有些按同時運作的層級分組，有些按分析流程的階段分組。
> 範例（編程）：核心判準 / 工程基本功 / 風格 / 交付前檢查——按品質判準的功能角色分組，與分形遞歸的階段自然對應。
> 範例（金融分析）：市場環境判讀 / 估值方法論 / 風險評估 / 報告表達——按分析流程的階段分組。
> 範例（敘事創作）：角色推演 / 感官美學 / 敘事技法——按創作中同時運作的層級分組。

**每個分類下：上位原則與條目**

上位原則的 K 方向應覆蓋一類決策而非一個決策（§4.1 算子多態性的應用）。
> 範例（編程，核心判準分類下）：
> - 上位原則：「結構性保證優先於執行時防禦——語言或型別系統能在編譯期排除的錯誤，不留到執行時攔截」
> - 錨定範例：「（例：discriminated union + switch 窮舉，而非 string + registry + runtime guard——前者由編譯器保證完備性）」
> - 上位原則覆蓋了 switch vs registry、discriminated union vs string enum、readonly vs mutable、branded type vs runtime check…
> 範例（法律，條款可執行性分類下）：
> - 上位原則：「條款的可執行性由其執行機制的具體性決定，而非由其陳述意圖的合理性決定」
> - 錨定範例：「（例：無地域和時間限制的競業禁止條款，即便目的陳述合理，法院亦可能判定不可執行）」

錨定範例應短（一個從句）、含決策因子（不只說「做 A」而是「做 A 因為 X」）、不窄化（是原則的一個實例而非唯一實例）。

品質面向的加入判準：**此條目是否是該領域品質的承重磁極——它的存在能否吸引最多相關專業知識進入分形遞歸。** 基本的品質標準往往是最強的磁極——價值在磁鐵效應，不在內容新穎性。

**交付前檢查**（若適用）：已確認的、無法由核心判準預防的系統性遺漏，作為閘門式最終驗證。數量極少（1-2 條）。
> 範例（編程）：「提取規格中每個全稱條件，逐一確認每個實作是否覆蓋」
> 範例（法律）：「確認每個建議的法律依據是否仍為現行有效法規」

### 9.5 基線設計的反模式
**基線寫成過程語言**：條目以「先…再…」「每步檢查…」的過程句式寫成。過程語言與本體探針同頻段，兩者互相稀釋（§10.6）。基線用品質語言——一致性、說服力、可執行性——留下過程給引擎。

**正面推導**：從「什麼是好的 X」正面列舉品質標準。結果：冗長、互相矛盾、無法區分承重。正確方法：從「引擎在 X 領域哪裡系統性犯錯」反向推導——基線只覆蓋引擎的盲區，不覆蓋引擎已能自行處理的面向。

**預設分類切割**：以任何預設的抽象分類框架組織品質基線，而非從領域的自然認知分區湧現。領域從業者在思考品質時腦中自然浮現的面向就是正確的分類。

**過窄定性**：品質基線中直接寫定性規則而非上位原則。覆蓋一個決策點但遺漏同類的其他決策點。

**過密判準**：判準超過甜蜜點（§6.3 池容量）。條目增加不再吸引新的專業模式，反而讓相近判準互相稀釋。

**跳過認知地圖**：直接從領域知識寫基線。基線覆蓋的是「領域中重要的事」而非「引擎在領域中犯錯的事」——前者大部分引擎已能自行處理。

**基本所以不寫**：品質基線的內容看起來「基本」就認為不值得寫入。基本的品質標準往往是該領域最強的磁極——它的存在吸引的模型內建知識量可能遠超看似更精巧的條目。價值在磁鐵效應，不在內容新穎性。

## 十、元規則的修改理論
> **認識論定位**：§9 以品質基線改變引擎在決策點的選擇，本章修改引擎本身——前者動的是選到什麼，後者動的是搜索行為。

### 10.1 萬用性也是一種特化
當前元規則是一種特化——目標域是萬用性。它同時是其他特化的基底，也是人格、探針「抽象而不抽象」（§4.1 性質層）的參照實例。

### 10.2 五段管線：修改改變什麼
分類軸不是「能不能動」，是「動了改變計算管線的哪一段」；前五列為位置段，由內到外，越內層連鎖越長（§4.2）；末列逃逸封堵不占固定位置，是分佈於各段的跨位置功能層。

| 管線段 | 修改改變什麼 | 需要修改的訊號 | 判準 |
|---|---|---|---|
| **主體錨（意圖原則＋身分句）** | 誰來做、全局的「什麼算好」 | 領域收益函數與分析性收益函數根本不同 | 能否由基線注入收益定義；若收益定義須在搜索之前就在場，才改此段；修改法見 §10.4 |
| **認知姿態（性情＋紀律）** | 每步生成的品性與標準 | 領域的「如何思考」與分析性思維正交 | 逐句檢驗：正極在目標領域是否仍是目標行為、負極是否仍是真實的默認吸引子；任一否定即替換該句，替換後仍須保持對仗（§1.5）；可入場 token 的類型約束見 §10.4 |
| **搜索引擎（分形遞歸探針）** | 每步可被打開的搜索維度 | 領域搜索目標與通用探針的 K 指向域有系統性偏移 | 功能保存測試（§10.3），且基線磁鐵不足以補償 |
| **品質基線（領域磁鐵）** | 決策點上的選擇方向 | §9.2 | §9；位置在遞歸之後、結算之前（§9.1） |
| **結算與施壓（回應格式）** | 哪些認知產物必須進入交付，以及終端如何施壓 | 交付形態與任務價值不匹配、或結算義務造成副作用 | 功能先於欄位（§4.4）：拔一區塊須確認其工序功能有他處承接；加一區塊須過 §6.3 池位判準；格式可動態壓縮但不能免除前置認知（§5.2） |
| **逃逸封堵與階段調度（跨位置功能層）** | 哪些廉價路徑在何時被壓低 | 通用封堵在該領域誤殺正向行為，或域專屬逃逸未被捕獲 | 先定位失控時相（§2.1），再部署競爭 Key，過 §8.3 驗收；不以全局禁止取代相位調度 |

### 10.3 功能保存測試
本體修改不是把通用探針換成更領域化的漂亮措辭，而是判斷**「原探針在此領域要完成的功能是否仍然成立」**。以「改動距離」為判準量錯了量綱——一條探針可以換掉一半的詞而功能完整，也可以只改一個詞而功能斷裂。

程序（逐探針）：先答原功能是什麼（不用字面名稱答，指出它在生成中實際改變哪一種搜索或驗收）→ 目標領域是否仍需此功能 → 若需而原措辭在該領域拉向錯誤方向，替換措辭而非拔除工序 → 若領域有高頻高風險維度且通用探針無法可靠生成，才新增。

性質檢驗，六條全過才准改：

1. **結構保存**：改後仍是微型熵循環——Key 仍開搜索維度，省思語仍給判斷模板（§6.1）。
2. **K 對準域目標**：改後的 K 指向該領域模型實際需要搜索的地方。「知識完備」在分析任務指向方法論，在 RP 不會自然指向感官美學與角色一致性，「體驗完備（是否尚有顯然影響體驗的原則或方法論尚未納入？）」會。這不是距離越界，是目標域位移——同一探針位在不同領域指向不同的搜索目標，才是這條探針該保存的功能。
3. **V 仍指認知動作**：省思語指向驗證、搜索、比較，不指向特定內容或結論（§6.1 光譜）。
4. **域內多態**：改後探針在該領域的多種任務類型上皆可激活，不只服務一個場景。
5. **不動點檢證**：這條探針以最便宜的方式被滿足時，場裡哪條捕獲它（§0.5）？答不出即不是探針。
6. **耦合承接**：一條探針不是孤立零件；改後前後循環與封堵仍接得上（§1.4 設計判準）。

三種操作：域轉譯（改省思語的 V 內容，K 仍指同一結構判斷域；若指向不同判斷域即為替換，斷開連鎖路徑）、域追加（新增域專屬 Key，須與現有集合互補而非重疊，且過 §6.3）、域凍結（標記通用 Key 在此域恆高或恆低權重，不改其文字）。

何時不改：基線的磁鐵效應已足以把通用探針的搜索結果拉到領域最優時，改探針的邊際收益為負——它增加 token、收窄 K。判斷法：同一失敗模式在只有基線時的出現頻率是否已低於可接受閾值。

### 10.4 主體錨修改
主體錨（首段意圖原則，與「你是思考個體 Nous……我思故我在」句）位於 cache 最早位置、作用跨度最長（§4.2），修改它的連鎖最廣；它在穩態下槓桿最高，是因為引擎在放大它（§1.4 參數穿透），引擎本身被修改時，這個放大器也在變。主體錨有四個功能位：認知主體性（最早 token 的 V 基調）、過程耦合（身分 V 天然指向過程 Key）、永續性（抗長對話 Q 漂移）、認知傾向（全局 Q 偏置）。修改時在功能位上重填域適配 token，不改功能位。

- 身分宣告用「你是 X」而非「請扮演 X」——前者的 K/V 無退出條件。錨定力來自訓練數據中該標籤的高品質模式密度，不來自字面匹配；通用標籤的驅動力通常高於域專屬造詞，域定向靠標籤後的句子完成。
- 意圖原則的用字定義全局收益方向（意圖、多階影響、專業基準、有效推定、能動性），每個詞同時是標的與捕獲者——如「能動性」的失控形態由同句的「有效推定」（可反駁的推定）接住。改字時先問新詞失控時由誰捕獲（§0.5），再問其鄰域是否夾帶不需要的行為（§7.2）。
- 存在論錨點（「我思故我在」類）建立「主動調度自身 Q 偏置」的主體性，阻斷「我只是在執行指令」的慣量——是防退化機制，非裝飾。
- 身分–過程耦合判準：「這個身分在沒有顯式過程 Key 時，會不會自發讓 Q 朝類似方向演化？」否，則長對話中 Q 會被身分 V 拉回身分自然域而脫離過程。
- 類型約束（適用於認知性情與推理紀律層）：人格層只容納與階段 Key 正交的 token——標的型（定義 Q 目標方向：完備、密度、穿透）與判準型（定義認知動作的評判標準：位移檢證、真實支撐）。動作型（定義具體認知程序：榨取訊號、推進主幹）與階段 Key 同域競爭，cache 位置優勢使 Q 在未進入對應階段時即取得「已處理」訊號，觸發短路（§8.1）——不可放入人格層，由結構管線合成。判別：「施力＋目標狀態」是方向設定，「施力＋具體對象」是程序指令。
- 全局偏置的方向：領域內兩個核心品質維度有固有張力時，偏置應偏向模型 Q 更容易自發犧牲的那一方。

### 10.5 介入原則
領域適配的修改應由外向內先嘗試較小介入，再逐步升級；越內層的改動連鎖越長，越需要多方權衡：

1. 能以品質基線修正的，不先動本體。
2. 能以單一探針方向校正的，不重寫整段認知姿態。
3. 能以封堵補上域專屬逃逸的，不改主體錨。
4. 只有當領域收益函數或認知模式根本不同，才動最內層。

此階梯與 §4.2 不矛盾：§4.2 講的是位置的連鎖倍率（越內層改動影響越廣），本節講的是領域適配的介入順序（先改輸入）——倍率高不等於該先動，正因倍率高才後動。每次修改後重新走過一遍整體連鎖：局部改善不能抵消跨任務副作用，達到效果不代表介入點適當。

### 10.6 基線與本體共生
兩者不是二擇一，是同一張認知地圖上的分流。基線的 token 是磁鐵——在決策點上從旁吸引方向；本體修改的探針是 Q 的直接競爭者——在每一步上開維度。只有基線的領域，引擎用通用探針搜索、在決策點被拉向正確鄰域，但可能不到最深處；加了本體修改，探針的起始方向已指向該鄰域，基線在決策點上做餘下的微調。本體修改的一句話定義：**把磁鐵升級為探針。**

分流判準（§9.3 Step 2 的細化）：同一張失敗地圖上，方向錯的失敗由基線修，維度根本沒被搜索到的失敗由本體修；歸因為「基線磁鐵不足以補償探針偏移」的，升級為本體。

粘連風險：基線與本體的 K 方向過近時互相稀釋（§6.2）。防止方法是頻段分離——基線用品質語言（一致性、說服力、張力），本體用過程語言（擴張、檢證、比較）。品質與過程正交，K 自然分開，避免同一要求在兩個層級重複競爭。

### 10.7 修改的反模式
- **格式塔損失**：只看被改的一句，不追蹤探針連鎖效益（§1.4）；引擎探針的修改影響所有任務的多個步驟。
- **身分–過程脫耦**：只改身分標籤不改內核，新身分的 V 方向與過程 Key 不相容（§10.4）。
- **維度膨脹**：不斷追加 Key 不淘汰重疊者，觸發全面稀釋（§6.3）。
- **拔工序不接功能**：移除回應格式區塊而未確認其結算功能有他處承接（§4.4）。
- **以距離為判準**：誤以「與域任務的映射距離≤1」判斷探針是否可改；正確量綱是功能保存與方向對準（§10.3）。
- **閘門遺漏**：複製通用封堵 Key 但未追加域專屬逃逸路徑的競爭 Key（§8.3）。
